VMN+ was a small consultancy in La Plata, Argentina where I cut my teeth as a professional developer — working across multiple clients and technologies simultaneously. It was the classic agency experience: diverse projects, fast context-switching, and exposure to everything from enterprise Java to PHP to Oracle.

I built web applications for clients across telecom and insurance: a deeply integrated insurance platform for Assursoft (Netherlands) using Java and Hibernate, a network management tool for Nextel Argentina using PHP/CakePHP, and Oracle Forms work for Claro Argentina's telecom systems.

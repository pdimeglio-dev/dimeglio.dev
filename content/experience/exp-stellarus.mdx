Stellarus is a healthcare solutions company that builds products and services for health plans, helping them automate operations, reduce costs and improve the experience for their members. Its solutions launched first with Blue Shield of California, as part of the Ascendiun family of companies.

I'm the team's AI engineer: I design and build the agent tooling the team runs on, and lead the technical side of its AI program.

The biggest piece is an agent system for security remediation. A Wiz scan found more than 5,000 vulnerabilities across the team's repos. I designed and built, on my own, a system where coding agents work them as campaigns. They group findings by root cause, locate each one, apply the fix in an isolated git worktree, prove the build with baselines before and after, and open a pull request that explains the change. Then they keep watching the build until it's green. The agents have opened more than 100 pull requests covering thousands of findings. The system keeps its own status for every finding, synced with Jira, and shows it in a React and TypeScript dashboard.

I also designed the team's AI Task Force. I started with a discovery of every AI tool in use, built a Codex plugin that publishes documentation straight to Confluence, and built proofs of concept for shared Codex and Copilot plugins so agent skills live in one place instead of scattered across repos. It's now a program where every engineer spends 30% of their time on AI work, and I help design the use cases they bring.

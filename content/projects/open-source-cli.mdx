# DevFlow CLI

A command-line tool that automates repetitive developer tasks like project scaffolding, git workflows, and deployment.

## Usage

```bash
# Scaffold a new project
devflow init my-project --template next-ai

# Run smart git workflow
devflow commit --ai  # AI-generated commit messages

# Deploy with confidence
devflow deploy --preview
```

## Features

- **AI-Powered Commits** — Generates meaningful commit messages from diffs
- **Template System** — Extensible project templates
- **Plugin Architecture** — Add custom commands via plugins

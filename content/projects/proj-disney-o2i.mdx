After proving deep system expertise through production support, I transitioned into a full stack development role on the O2I (Order to Inventory) suite — building new features and improving the platform that securely moved Disney's most valuable entertainment assets around the world.

### Key Achievements
* **Full Stack Feature Development:** Built features across the Spring Boot backend and Angular frontend, delivering end-to-end functionality for asset management, transfer tracking, and user workflows.
* **High-Speed Asset Delivery:** Worked with [Aspera Faspex](https://www.ibm.com/products/aspera) and [Signiant](https://www.signiant.com/) — specialized high-speed transfer protocols designed for moving massive media files (multi-GB feature films and uncompressed assets) across global networks reliably and securely.
* **Security-First Development:** Built within Disney's strict security requirements for handling unreleased content, ensuring all transfers were encrypted, audited, and compliant with studio security policies.

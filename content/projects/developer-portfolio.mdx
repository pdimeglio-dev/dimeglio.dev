# Developer Portfolio

The site you're looking at right now! Built from scratch using modern web technologies.

## Tech Stack

- **Next.js 16** — App Router with React Server Components
- **Tailwind CSS v4** — Utility-first styling with `@theme inline` configuration
- **shadcn/ui** — Beautiful, accessible component library
- **MDX** — Content authored in Markdown with JSX components
- **Framer Motion** — Smooth animations and transitions

## Design Philosophy

The design follows an "Apple meets Gen AI startup" aesthetic:

- True black (#000000) background
- Pure white text for maximum contrast
- Frosted glass navigation bar
- Subtle radial gradients and glow effects

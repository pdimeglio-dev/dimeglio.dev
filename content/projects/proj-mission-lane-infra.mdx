Mission Lane's legacy monolithic architecture was a bottleneck for a rapidly growing fintech — every deployment risked the entire financial platform, and scaling individual features meant scaling everything. The team needed to decompose the monolith into microservices while keeping active banking products running with zero downtime.

### Key Achievements
* **Full Stack Migration:** Built the consumer-facing UI in React while decomposing the legacy backend into Kotlin microservices, delivering a modern full-stack architecture across the entire platform.
* **Monolith Decomposition:** Led the migration from a monolithic architecture to independently deployable microservices, enabling teams to ship features faster without risking the entire financial platform.
* **Distributed Team Leadership:** Led a team of 5+ offshore engineers, establishing sprint cadences, code review standards, and architectural decision records that kept delivery velocity high across time zones.
* **Cloud-Native Infrastructure:** Built and maintained services on GCP with Kubernetes, Terraform, and Helm — achieving reproducible deployments and infrastructure-as-code across multiple environments.
* **Full Observability Stack:** Implemented end-to-end monitoring with Prometheus, Grafana, and the ELK Stack, enabling real-time alerting and rapid incident response for financial transactions.
* **Event-Driven Architecture:** Designed asynchronous workflows using GCP Pub/Sub for inter-service communication, decoupling critical payment processing pipelines from synchronous request flows.

Developer velocity across the team was bottlenecked by constant context-switching — jumping between Slack, GitHub, Calendar, and email dozens of times a day. For a distributed team shipping on 4-week cycles, even small friction points compound fast. Rather than adopt yet another dashboard, we built a tool that meets engineers where they already live: the terminal.

### Key Achievements
* **Unified AI Interface:** Integrated Large Language Models directly with Slack, GitHub, Calendar, and email, giving developers a single AI-powered terminal to manage communications, pull requests, scheduling, and code reviews without leaving their workflow.
* **3-Week Ship:** Designed and delivered the complete platform in 3 weeks using AI-assisted development, resulting in a 40% efficiency gain across the engineering team.
* **React + Ink TUI:** Built with React and [Ink](https://github.com/vadimdemedes/ink) to create a rich terminal UI — bringing component-driven architecture and the same React mental model to the command line.

Wells Fargo's Store Vision Platform was the daily driver for thousands of in-branch bankers — but its jQuery frontend was showing its age. The modernization effort went through multiple phases as the team navigated real-world constraints of enterprise browser compatibility and framework maturity.

### Key Achievements
* **jQuery → Polymer Migration:** Contributed to the first phase of modernization, migrating legacy jQuery components to Google's Polymer web components framework for a more structured, component-based architecture.
* **IE Memory Leak Debugging:** Helped diagnose and debug critical memory leaks in Polymer running on Internet Explorer — a showstopper for an enterprise banking environment where IE was still the standard browser.
* **Polymer → Angular Pivot:** After the IE compatibility issues, contributed to the strategic pivot from Polymer to Angular, migrating the frontend to a more mature and enterprise-ready framework.
* **Full Stack Delivery:** Worked across the full stack, integrating frontend components with Java backend services and maintaining end-to-end test coverage with JUnit.

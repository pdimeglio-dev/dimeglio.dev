When I joined, AI use on the team was scattered: different tools, different habits, and agent skills copied into random branches in whichever repo someone happened to be working in. I designed the AI Task Force to fix that, and I lead it on the technical side.

### Discovery First

I started with a discovery of every AI tool already in use across the team: what it was, who used it, and for what. That became the baseline for deciding what to standardize and what to drop.

### A Codex Plugin That Publishes to Confluence

Writing documentation by hand in Confluence meant it fell behind the code. I built a Codex plugin that publishes documentation straight to Confluence, used it to document the discovery, and laid out the structure of the team's Confluence space. The same publisher later powered the status dashboard for the vulnerability campaigns.

### Shared Plugins Instead of Scattered Skills

I built proofs of concept for shared Codex and Copilot plugins, so skills and agent instructions live in one place the whole team installs, instead of being copied between repos and drifting apart.

### From Initiative to Program

The Task Force now has a manager and a Scrum Master, and every engineer on the team gets 30% of their time for AI work. Engineers bring their own AI use cases, and I help them shape the design and get them built. Two of the current ones:

* **AI Code Reviewer.** A developer on the team built a code review agent as a CLI. I'm helping them write it up in Confluence: which metrics to capture, how to grow adoption, and how to get leadership's buy-in. We're now designing how to turn it into something every team can use, with Bitbucket CI/CD pipelines calling the reviewer agent running in Azure.
* **QA tools.** A set of agent tools that refine Jira tickets, generate test cases from them, and implement API tests.

### Key Achievements

* **Designed the AI Task Force and lead it on the technical side**, now a program where every engineer spends 30% of their time on AI work.
* **Technical design support** for the AI use cases engineers bring to the program, including taking an AI code reviewer from a CLI to a shared service wired into Bitbucket CI/CD on Azure, and QA tools that refine Jira tickets and generate test cases and API tests.
* **Full discovery of the AI tools in use**, documented in Confluence.
* **Built a Codex plugin that publishes to Confluence**, reused later for the vulnerability campaign dashboard.

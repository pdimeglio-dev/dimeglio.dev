Disney Parks' digital platform serves millions of guests annually — powering everything from resort bookings and dining reservations to park tickets and in-park experiences. The backend services needed to be fast, reliable, and capable of handling massive traffic spikes during peak seasons and special events.

### Key Achievements
* **Scalable REST APIs:** Developed RESTful Web Services using Java, Spring MVC, and JPA that powered guest-facing features across Disney's web and mobile platforms, handling millions of requests from park guests worldwide.
* **Enterprise Java Architecture:** Built within Disney's enterprise Java ecosystem — working with Spring Boot, JPA for data access, and JUnit/Mockito for comprehensive test coverage across all service layers.
* **High-Traffic Performance:** Engineered services to handle the traffic patterns unique to theme parks — massive spikes during park openings, holiday seasons, and special event launches that required careful capacity planning and graceful degradation.
* **Foundation for Growth:** This role was the beginning of a 14+ year career in enterprise software — building the fundamentals of distributed systems, API design, and production-grade engineering that would scale through Google, fintech, and AI.

# Hello World

Welcome to my blog! This is the first post on my new developer portfolio, built with **Next.js 16**, **Tailwind CSS v4**, and **MDX**.

## Why Next.js 16?

Next.js 16 brings some exciting changes:

- **React Server Components** by default
- `params` and `searchParams` are now **Promises**
- New `PageProps` and `LayoutProps` type helpers
- **Turbopack** for faster development

## Code Example

Here's a simple React Server Component:

```tsx
export default async function BlogPost({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const post = await getPost(slug);

  return (
    <article>
      <h1>{post.title}</h1>
      <div>{post.content}</div>
    </article>
  );
}
```
